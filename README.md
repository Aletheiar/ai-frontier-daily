## 定时任务配置参考

1. 在桌面应用侧栏打开 Scheduled / 定时任务，新建任务。也可尝试入口：[打开定时任务创建页](codex://automations)。
2. 名称填写“AI 前沿日报与研究想法”。选择本地项目 `D:\Code\GitHub\前沿`，执行位置选择 Local / 本地，以便日报直接保存在这个文件夹中。
3. 时间选择每天 09:00，时区 Asia/Shanghai。若界面提供高级 RRULE，填写 `FREQ=DAILY;BYHOUR=9;BYMINUTE=0;BYSECOND=0`，并另行确认时区。
4. 将 [每日任务提示词.md](每日任务提示词.md) 的全文复制到任务指令中。任务需具备联网检索、本目录读写和 GitHub 仓库推送能力；本地 GitHub CLI 的登录凭据不写入仓库。
5. 保存并启用；先执行一次 Run now / 立即运行，确认 daily/ 产生对应日报、最终摘要出现在 Scheduled。检查应用和 Windows 的通知设置；通知是否弹出仍需实际验证。

需要本地文件的任务要求电脑保持开机、应用保持运行、项目目录可以访问。Web 任务不能直接写入电脑文件夹。以上依据 [OpenAI 官方定时任务文档](https://learn.chatgpt.com/docs/automations?surface=app)，查阅日期为 2026-10-27。

这里不配置邮件、飞书或微信通道；默认交付位置是应用内任务结果。将来更改通道时，需明确收件目的地再配置。
